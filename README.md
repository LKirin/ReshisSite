# Решись Авиа — Веб-сервис динамического ценообразования авиабилетов

Веб-приложение для расчета прогноза спроса, продаж и финансовых показателей авиарейсов на основе обученной ML-модели (Вариант C: полнофункциональный веб\-сервис с backend API на FastAPI и интерактивным интерфейсом).

---

## 🛠 Стек технологий и ИИ-инструменты

* **Backend:** Python 3.10+, FastAPI, Uvicorn, Pandas, Pydantic  
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla), Chart.js
---

## 📁 Структура проекта

```
├── data/
│   ├── my_forecast.csv     # Файл с квантильными прогнозами спроса (из ML-части)
│   ├── routes.csv          # Справочник маршрутов (скачивается автоматически при первом запуске)
│   └── users.json          # База пользователей и сессий (создается автоматически)
├── index.html              # Веб-интерфейс сервиса
├── main.py                 # FastAPI сервер и расчетный движок
├── requirements.txt        # Список зависимостей Python
└── README.md               # Руководство по установке и запуску
```

## ⚙️ Установка и запуск

### 1\. Предварительные требования

* Установленный **Python 3.10** или выше  
* Установленный менеджер пакетов **pip**

### 2\. Клонирование репозитория

```sh
git clone https://github.com/LKirin/ReshisSite.git
cd <ИМЯ_ПАПКИ_ПРОЕКТА>
```

### 3\. Создание и активация виртуального окружения

* **Linux / macOS:**

```sh
python3 -m venv venv
source venv/bin/activate
```

* **Windows:**

```sh
python -m venv venv
venv\Scripts\activate
```

### 4\. Установка зависимостей

```sh
pip install --upgrade pip
pip install -r requirements.txt
```

### 5\. Подготовка данных

Убедитесь, что файл с прогнозами **`my_forecast.csv`** (результат выполнения блока ML) помещен в директорию **`data/`**:

```
data/my_forecast.csv
```

*(Справочник `routes.csv` автоматически скачается с официального источника при старте приложения, если он отсутствует).*

### 6\. Запуск сервера

Запустите приложение командой:

```sh
python main.py
```

или через uvicorn напрямую:

```sh
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

После старта веб\-интерфейс доступен в браузере по адресу: 👉 [**http\://127.0.0.1:8000**](http://127.0.0.1:8000) (или [**http\://localhost:8000**](http://localhost:8000))
